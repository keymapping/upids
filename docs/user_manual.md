## 1. 系统概述

### 1.1 系统简介

**UPIDS（Urban Pipeline Inspection and Detection System）** 是一套地下管线智能缺陷检测系统，旨在替代传统人工巡检模式，实现管线结构数据的数字化管理与缺陷自动识别。

### 1.2 核心功能

| 功能模块 | 说明 |
|----------|------|
| 用户管理 | 用户注册、登录、权限控制 |
| GIS地图 | 管线可视化、缺陷标注、空间查询 |
| 管线管理 | 管线数据导入、查询、删除 |
| 巡检管理 | 图像上传、检测记录查看 |
| 任务管理 | 异步检测任务监控、重试 |
| 预警中心 | 缺陷预警、告警处理 |
| 数据分析 | 统计图表、趋势分析 |
| 风险报告 | 报告生成、导出 |

### 1.3 用户角色

| 角色 | 权限 |
|------|------|
| **管理员** | 用户管理、系统配置、全量数据管理、模拟数据生成 |
| **普通用户** | 数据查看、任务查询、预警处理 |

## 2. 快速开始

### 2.1 启动服务

系统需要启动以下四个服务：

1. **数据库服务**（PostgreSQL + Redis）
   ```bash
   cd /d/java_web/UPIDS/UPIDS
   docker-compose up -d
   ```

2. **后端服务**（Spring Boot）
   ```bash
   cd /d/java_web/UPIDS/UPIDS/backend
   mvn spring-boot:run
   ```

3. **Python识别服务**（Flask）
   ```bash
   cd /d/java_web/UPIDS/UPIDS/python-service
   python app.py
   ```

4. **前端服务**（Vue3）
   ```bash
   cd /d/java_web/UPIDS/UPIDS/frontend
   npm run dev
   ```

### 2.2 访问地址

| 服务 | 地址 |
|------|------|
| 前端应用 | http://localhost:5173 |
| 后端API | http://localhost:8080 |
| Python服务 | http://localhost:5000 |

## 5. GIS地图

### 5.1 页面概述

GIS地图页面提供管线和缺陷的空间可视化展示。

### 5.2 功能说明

**左侧控制面板**：

| 控制项 | 说明 |
|--------|------|
| 管线图层开关 | 显示/隐藏管线层 |
| 缺陷图层开关 | 显示/隐藏缺陷点层 |
| 缺陷类型筛选 | 按裂缝/腐蚀/断裂筛选 |
| 严重等级筛选 | 设置最低严重等级过滤 |
| 刷新按钮 | 重新加载地图数据 |
| 图例说明 | 管线和缺陷等级的颜色标识 |

**地图区域**：

- 蓝色线条表示管线
- 红色圆点表示高等级缺陷（等级4-5）
- 橙色圆点表示中等级缺陷（等级2-3）
- 黄色圆点表示低等级缺陷（等级1）

### 5.3 操作指南

**查看管线详情**：

1. 在地图上点击管线
2. 弹出管线详情弹窗，显示编号、名称、材质、管径、缺陷数等信息

**查看缺陷详情**：

1. 在地图上点击缺陷点
2. 弹出缺陷详情弹窗，显示缺陷类型、严重等级、置信度等信息

| 区域编码 | 按区域编码搜索 |

| 列名 | 说明 |
|------|------|

1. 在表格中找到目标管线

## 13. 常见问题

### 13.1 登录问题

**Q：输入正确的用户名和密码后无法登录？**

**A**：请检查以下几点：
1. 后端服务是否已启动（http://localhost:8080）
2. 数据库服务是否已启动（docker-compose up -d）
3. 用户名和密码是否区分大小写

### 13.2 GIS地图问题

**Q：GIS地图无法加载或显示空白？**

**A**：请检查以下几点：
1. 网络是否正常（地图瓦片服务需要外网访问）
2. 后端服务是否正常运行
3. 是否已导入管线数据（可通过「系统管理」→「模拟数据」生成）

### 13.3 任务执行问题

**Q：任务状态显示「失败」？**

**A**：可能的原因：
1. Python识别服务未启动（需要启动python-service）
2. 图像文件路径错误
3. 网络连接问题

可点击「重试」按钮重新执行任务。

### 13.4 数据导入问题

**Q：导入管线数据失败？**

**A**：请检查以下几点：
1. 文件格式是否正确（GeoJSON或Excel）
2. 文件内容是否符合数据规范
3. 是否有重复的管线ID

### 13.5 权限问题

**Q：某些按钮无法点击或页面无法访问？**

**A**：请检查当前用户角色：
- 管理员：拥有全部权限
- 普通用户：仅拥有查看和查询权限
