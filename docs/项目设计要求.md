AI 智启未来·算法与 Web 开发第二届创新赛
——计科专业 2026 年实践挑战赛
为激发学生对人工智能与 Web 开发的综合应用能力，推动新工科背景下计算机类专业课程
与实践融合，特举办“AI 智启未来·算法与 Web 开发创新赛”。本次比赛将以“算法+AI 模型
+Web 开发”为主题，鼓励学生围绕智能系统设计、AI 能力集成与算法问题、智慧养殖等方
向，构建具有创意与实用性的项目系统。
 一、参赛对象
全体计算机科学与技术专业 23 级学生（4-5 人组队参赛）
 二、赛程安排（拟定）
• 课题发布：2026 年 6 月 26 日
• 项目开发：2026 年 6 月 26 日 — 7 月 7 日
• 项目展示与答辩：2026 年 7 月 8 号
• 结果公布与表彰：比赛当场

 五、组织单位
主办单位：计算机科学与技术学院
统一设计要求规范
一、项目开发总体要求（所有题目统一）
每个课题均要求以 Java Web 工程化系统开发为目标，实现完整的：系统
必须具备真实工程结构，不得为静态页面或纯展示系统。
二、开发团队要求（4-5 人标准分工）
每组必须明确分工如下：
角色划分（必须明确写入文档）
① 后端开发（1 人）
Spring Boot 接口开发
数据库设计与实现
业务逻辑实现
接口文档编写（Swagger）
② 数据/算法处理（1 人）
数据清洗模块
特征提取（声纹/图像/时序）
简单模型（可调用 Python 或 Java 实现）
数据分析模块实现
③ 前端开发（1 人）
Vue3 页面开发
ECharts/Canvas 可视化
GIS/图表展示模块
UI 交互设计
④系统集成/测试/文档（1 人）
系统联调
接口测试
压力测试
软著文档整理
PPT 答辩材料制作
三、系统必须包含的工程模块（强制）
每个项目必须包含以下 6 大模块：
1）用户与权限模块
登录/注册
角色权限（管理员/普通用户）
2）数据接入模块
API 接口接入（REST）
或模拟数据生成器
支持批量导入
3）数据存储模块
MySQL 数据库
至少 5 张核心表
支持历史数据存储
4）业务处理模块（核心）
声纹识别 / 图像识别 / GIS 分析 / 规则引擎
至少一个“算法/分析逻辑模块” 
5）可视化模块
ECharts 图表
统计分析图
GIS 地图（如涉及空间数据）
6）预警/决策模块（必须）
阈值判断
异常检测
告警输出（页面+日志）
四、数据库设计要求（强制规范）
每个系统必须满足：
至少 5 张表
必须包含：
用户表
数据采集表
业务分析表
结果输出表
日志/记录表
并要求：
有主键设计
有索引设计
有时间字段（必须支持历史分析）
五、系统技术要求（统一标准）
后端：
Spring Boot 2.x / 3.x 
MyBatis / MyBatis-Plus 
RESTful API 
数据库：
MySQL 8.0 
前端：
Vue3 或 Vite 
ECharts（必须）
Axios 接口调用
可选增强：
Redis 缓存（加分项）
WebSocket 实时推送（加分项）
Python 算法模块（加分项）
六、系统功能复杂度要求
必须满足：
数据规模要求

处理逻辑要求
必须包含至少 1 种：
时间序列分析
