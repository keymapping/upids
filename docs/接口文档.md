## 1. 通用说明

### 1.1 协议与格式

| 项 | 说明 |
|----|------|
| 协议 | HTTP/HTTPS |
| 数据格式 | JSON（`Content-Type: application/json`） |
| 字符编码 | UTF-8 |
| 时间格式 | `yyyy-MM-dd HH:mm:ss`（时区 `Asia/Shanghai`） |
| 日期格式 | `yyyy-MM-dd` |

### 1.2 统一响应体

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": 1719667200000
}
```

### 1.3 分页请求参数（Query）

| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| page | int | 否 | 1 | 页码，从 1 开始 |
| pageSize | int | 否 | 20 | 每页条数，最大 100 |

### 1.4 分页响应 data

```json
{
  "list": [],
  "total": 100,
  "page": 1,
  "pageSize": 20
}
```

### 1.5 错误码

| code | message 示例 | 说明 |
|------|--------------|------|
| 200 | success | 成功 |
| 400 | 参数校验失败 | 缺少必填项、格式错误 |
| 401 | 未登录或 Token 已过期 | 需重新登录 |
| 403 | 无权限访问 | 角色不足 |
| 404 | 资源不存在 | ID 无效 |
| 409 | 用户名已存在 | 唯一约束冲突 |
| 500 | 服务器内部错误 | 未预期异常 |
| 503 | 识别服务不可用 | Python 服务超时或宕机 |

### 1.6 鉴权

除白名单外，请求头须携带：

```
Authorization: Bearer <token>
```

**白名单：**

- `POST /api/auth/login`
- `GET /api/health`
- Swagger/Knife4j 文档路径

### 1.7 枚举定义

**role（用户角色）**

| 值 | 说明 |
|----|------|
| admin | 管理员 |
| user | 普通用户 |

**taskStatus（识别任务状态）**

| 值 | 说明 |
|----|------|
| pending | 待处理 |
| running | 处理中 |
| done | 已完成 |
| failed | 失败 |

**defectType（缺陷类型）**

| 值 | 说明 |
|----|------|
| none | 无缺陷 |
| crack | 裂缝 |
| corrosion | 腐蚀 |
| fracture | 断裂 |

**alertType（预警类型）**

| 值 | 说明 |
|----|------|
| threshold | 严重等级超阈值 |
| anomaly | 短期缺陷数异常增多 |

**defectSource（检测来源）**

| 值 | 说明 |
|----|------|
| rule | 规则引擎 |
| ai | AI 识别 |
| fusion | 融合结果 |

## 3. 认证模块

### POST /api/auth/login

**描述**：用户登录

**权限**：公开

**请求 Body**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | string | 是 | 用户名，3–50 字符 |
| password | string | 是 | 密码，6–50 字符 |

**请求示例**

```json
{
  "username": "admin",
  "password": "admin123"
}
```

**响应 data**

| 字段 | 类型 | 说明 |
|------|------|------|
| token | string | JWT Token |
| expiresIn | long | 过期秒数 |
| userInfo | object | 用户信息 |

**userInfo 结构**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | long | 用户 ID |
| username | string | 用户名 |
| realName | string | 真实姓名 |
| role | string | admin / user |

**响应示例**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "expiresIn": 86400,
    "userInfo": {
      "id": 1,
      "username": "admin",
      "realName": "系统管理员",
      "role": "admin"
    }
  },
  "timestamp": 1719667200000
}
```

**错误示例**

```json
{ "code": 400, "message": "用户名或密码错误", "data": null, "timestamp": 1719667200000 }
```

---

**描述**：注册新用户

**请求 Body**

| 字段 | 类型 | 必填 | 说明 |

| password | string | 是 | 密码 |

  "username": "inspector01",

**响应 data**：同 userInfo 结构

## 5. 管线模块

### POST /api/pipelines/import

**描述**：批量导入管线 GIS 数据

**权限**：admin、user

**Content-Type**：`multipart/form-data`

**表单参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | file | 是 | GeoJSON 或 Excel（.xlsx） |

| 列名 | 必填 | 说明 |
|------|------|------|
| pipeline_id | 是 | 管线编号 |
| pipeline_name | 否 | 名称 |
| coordinates | 是 | WKT LINESTRING 或 "lng,lat;lng,lat" |
| material_type | 否 | 材质 |
| diameter | 否 | 管径 mm |
| install_time | 否 | yyyy-MM-dd |
| region_code | 否 | 区域编码 |

**响应 data**

```json
{
  "importId": "imp_20260629_001",
  "totalCount": 1500,
  "successCount": 1498,
  "failCount": 2,
  "failDetails": [
    { "row": 12, "reason": "coordinates 格式错误" }
  ]
}
```

### POST /detect

## 17. 前后端 TypeScript 类型参考

```typescript
// 统一响应
interface ApiResult<T = unknown> {
  code: number
  message: string
  data: T
  timestamp: number
}

// 分页
interface PageResult<T> {
  list: T[]
  total: number
  page: number
  pageSize: number
}

// 登录
interface LoginRequest {
  username: string
  password: string
}

interface LoginResponse {
  token: string
  expiresIn: number
  userInfo: UserInfo
}

interface UserInfo {
  id: number
  username: string
  realName: string
  role: 'admin' | 'user'
}

// 缺陷
interface DefectVO {
  defectId: number
  recordId: number
  pipelineId: string
  defectType: 'none' | 'crack' | 'corrosion' | 'fracture'
  severityLevel: number
  confidenceScore: number
  source: 'rule' | 'ai' | 'fusion'
  location?: { lng: number; lat: number }
  detectedAt: string
}

// 任务
interface TaskVO {
  taskId: number
  recordId: number
  status: 'pending' | 'running' | 'done' | 'failed'
  retryCount: number
  errorMessage?: string
  startedAt?: string
  finishedAt?: string
  createdAt: string
}
```
